# Bella Vista restaurant menu demo

A mobile-first, single-page restaurant website and QR menu demo.

## Run locally
Open `index.html` in a browser. Food photography is loaded from Unsplash, and the Manrope font is loaded from Google Fonts, so an internet connection is needed for those assets.

## Included
- Responsive dark premium layout
- Category filters and live dish search
- Fictional sample menu with descriptions and USD prices
- Restaurant information section
- Mobile quick navigation
- Reduced-motion support and keyboard focus styles

All restaurant details, menu items, and prices are fictional demo content. Replace them with the restaurant's real information before publishing.
